# 経済産業省 第３次産業活動指数・商業動態統計

経済産業省が公表する2つの統計を、SQL で検索・集計できるテーブルにしたデータセットです。サービス産業の活動指数と商業販売額を収録しています。

## 出典と利用条件

- [第３次産業活動指数](https://www.meti.go.jp/statistics/tyo/sanzi/)（経済産業省 経済解析室）
- [商業動態統計調査](https://www.meti.go.jp/statistics/tyo/syoudou/)（経済産業省）

経済産業省ウェブサイトのコンテンツに準拠する[公共データ利用規約（第1.0版）（PDL1.0）](https://www.meti.go.jp/main/rules.html)に従います。

出典の表記:

- 「第３次産業活動指数」（経済産業省）（https://www.meti.go.jp/statistics/tyo/sanzi/）を加工して作成。
- 「商業動態統計調査」（経済産業省）（https://www.meti.go.jp/statistics/tyo/syoudou/）を加工して作成。

いずれも公表 Excel の表を機械可読な行の形に整形しています。統計値そのものは変更していません。

## テーブル

| テーブル | 内容 | 行数 |
| --- | --- | ---: |
| `main.tertiary_industry_activity_index` | 第３次産業活動指数（2020年基準）の業種別・月次の指数（2020年=100） | 52,416 |
| `commerce.commercial_sales_by_industry` | 商業動態統計調査の業種別・月次の商業販売額（10億円、全国） | 14,674 |
| `commerce.retail_sales_by_business_type_and_item` | 商業動態統計調査の、百貨店・スーパー・コンビニエンスストアなど業態別・商品分類別の月次販売額（全国） | 29,551 |

## 使い方

小売業の販売額を年ごとに合計する:

```sql
SELECT year, sum(sales_value_billion_yen) AS sales_billion_yen
FROM meti.commerce.commercial_sales_by_industry
WHERE industry_name = '小売業計'
GROUP BY ALL
ORDER BY year;
```

電力調査統計・総合エネルギー統計・石油製品価格調査は、資源エネルギー庁のデータセット [enecho](https://github.com/queria-io/dataset-enecho) にあります。

## 注意

- 多くのテーブルは合計と内訳（と再掲）を同じ列に持ちます。絞らずに合計すると二重に数えるので、各テーブルの説明で合計の行や列を確認してください。
- 値は原典の公表値のままで、調査の見直しをまたぐ接続処理はしていません。

## main.tertiary_industry_activity_index

業種（品目）×月×系列種別を1レコードとする月次指数です。2018年1月以降を収録します。

- item_code: 品目番号（VARCHAR、例: K1D000000I = 第３次産業総合）
- item_name: 品目名称（VARCHAR、業種名）
- weight: ウエイト（DOUBLE、2020年基準の付加価値額ウエイト。第３次産業総合=10000）
- series_type: 系列種別コード（VARCHAR、seasonally_adjusted / original）
- series_type_ja: 系列種別名（VARCHAR、季節調整済指数 / 原指数）
- year_month: 年月（VARCHAR、YYYYMM）
- year: 年（INTEGER）
- month: 月（INTEGER）
- index_value: 指数値（DOUBLE、2020年＝100）

品目（item_code / item_name）は「第３次産業総合」から日本標準産業分類の大分類・中分類・
個別業種までの階層を含みます。

## commerce.commercial_sales_by_industry

業種×月を1レコードとする商業販売額です。1980年1月以降を収録します。
指数ではなく販売額そのもので、単位は10億円です。全国の値のみで、地域別の内訳はありません。

- fiscal_year: 年度（INTEGER、4月始まり）
- year: 年（INTEGER）
- month: 月（INTEGER）
- year_month: 年月（VARCHAR、YYYYMM）
- industry_order: 原典の統計表での業種の並び順（INTEGER）
- industry_name: 業種名（VARCHAR）
- industry_name_en: 業種名（VARCHAR、英語）
- sales_value_billion_yen: 商業販売額（DOUBLE、10億円）

### 利用上の注意

商業計・卸売業計・小売業計と、その内訳の業種、内訳を足し上げた参考系列（「参考１(自動車小売業、
機械器具小売業、燃料小売業、医薬品化粧品小売業、その他小売業の計)」など）が同じ列に並びます。
業種を絞らずに合計すると二重計上になります。industry_order は原典の統計表での並び順で、
合計とその内訳の対応を追うのに使えます。

小売業の内訳には無店舗小売業（通信販売・ネット販売）が別掲されています。

販売額は原典の公表値そのままで、調査の見直しをまたぐ接続処理はしていません。次の時点で
水準に不連続があります。

| 時点 | 理由 |
| --- | --- |
| 1998年4月 | 平成11年商業統計調査で既設の対象事業所を捕そく |
| 1999年4月 | 自動車卸売業における販売額の定義変更 |
| 2015年7月 | 無店舗小売業の表章を開始 |
| 2020年3月 | 水準の調整 |
| 2025年1月 | 水準の調整 |

1989年以前も、貴金属ディーリングに係る取引額の除外（1990年まで遡及）と日本標準産業分類の
改訂（1989年まで遡及）で不連続です。原典は、これらの期間をまたぐ前年比をリンク係数で算出した
と注記しており、係数そのものは原典の注シートにあります。このテーブルには適用していません。

集計に必要なデータが無い月（原典の「***」）と秘匿された値（「X」）は行ごと落としています。

## commerce.retail_sales_by_business_type_and_item

業態×商品分類×月を1レコードとする業態別・商品別販売額です。販売額の単位は百万円、
店舗数は店です。全国の値のみで、地域別の内訳はありません。

- fiscal_year: 年度（INTEGER、4月始まり）
- year: 年（INTEGER）
- month: 月（INTEGER）
- year_month: 年月（VARCHAR、YYYYMM）
- business_type: 業態（VARCHAR）
- item_order: 原典の統計表での商品分類の並び順（INTEGER）
- item_name: 商品分類名（VARCHAR）
- item_name_en: 商品分類名（VARCHAR、英語）
- sales_value_million_yen: 販売額（DOUBLE、百万円）
- establishments: 期末の店舗数（BIGINT、店）

業態と収録期間は次のとおりです。

| business_type | 収録期間 | 項目数（合計・店舗数を含む） |
| --- | --- | --- |
| 百貨店・スーパー | 1980年1月〜 | 13 |
| 百貨店 | 1980年1月〜 | 13 |
| スーパー | 1980年1月〜 | 13 |
| コンビニエンスストア | 1997年4月〜 | 7 |
| 家電大型専門店 | 2014年1月〜 | 18 |
| ドラッグストア | 2014年1月〜 | 11 |
| ホームセンター | 2014年1月〜 | 11 |

### 利用上の注意

「百貨店・スーパー」は百貨店とスーパーの合計です。業態を絞らずに合計すると二重計上になります。
商品分類も合計（「合計」「商品販売額」）と内訳が同じ列に並ぶため同様です。

item_name は業態ごとに体系が違い、同じ名前の商品分類が1つの業態に複数あります（家電大型専門店の
「その他」は item_order 15 と 17 の2つ）。商品分類を指すときは business_type と item_order の
組で指します。

sales_value_million_yen と establishments はどちらか一方だけが入ります（店舗数の行では
販売額が NULL）。店舗数を持つのはコンビニエンスストア・家電大型専門店・ドラッグストア・
ホームセンターだけです。

販売額は原典の公表値そのままで、調査の見直しをまたぐ接続処理はしていません。次の時点で
水準に不連続があります。

| business_type | 不連続の時点 |
| --- | --- |
| 百貨店・スーパー / 百貨店 / スーパー | 1991年7月・1994年7月・2010年7月・2013年7月・2015年7月・2020年3月 |
| コンビニエンスストア | 2012年1月・2017年1月・2021年3月 |
| 家電大型専門店 | 2018年1月・2020年3月 |
| ドラッグストア | 2015年1月・2017年1月・2018年1月・2019年1月 |
| ホームセンター | 原典に不連続の注記なし |

原典は、不連続の前の期間にリンク係数を乗じると後の期間と接続すると注記しており、係数そのものは
原典の注シートにあります。このテーブルには適用していません。直近の年の1月分以降は年間補正で
値が変わることがあります。

集計に必要なデータが無い月（原典の「***」）と秘匿された値（「X」）は行ごと落としています。
コンビニエンスストアは1997年1月から表に行がありますが、値が入るのは1997年4月分からです。
